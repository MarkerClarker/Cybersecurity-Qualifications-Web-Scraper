# Cybersecurity Qualifications Web Scraper

This project collects information from cybersecurity job postings. It looks for common certifications, skills, and qualifications that employers request.

The results can help show which cybersecurity qualifications are most commonly mentioned in job postings.

## What It Does

- Collects cybersecurity job-posting information
- Looks for common certifications and skills
- Counts how often qualifications appear
- Creates charts to display the results

## Tools Used

- Python
- BeautifulSoup
- Pandas
- Matplotlib

## Getting Started

Clone the repository:

```bash
git clone https://github.com/MarkerClarker/Cybersecurity-Qualifications-Web-Scraper.git
```

Open the project folder:

```bash
cd Cybersecurity-Qualifications-Web-Scraper
```

## Running the Project

Run the main Python file in the project folder:

```bash
python your_file_name.py
```

Replace `your_file_name.py` with the name of the project's Python file.

## Results

The project may create:

- Lists of common certifications
- Lists of common cybersecurity skills
- Tables of results
- Charts showing qualification trends

## Important Notes

The results depend on the job postings that are collected. They may not represent every cybersecurity job or employer.

Websites can also change their layout, which may affect the scraper.

Please follow each website's rules when collecting information.

*Note: This is stricly meant for use in understanding cybersecurity analyst positions. You are free to rework the code to whatever end, but the regular expressions are heavily catered towards its initial purpose, so good luck and godspeed!*
